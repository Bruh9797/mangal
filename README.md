# МАНГАЛ

Магазин мангалов по индустриальному концепту №1. Next.js App Router, JavaScript, обычный CSS. Главная страница, три страницы моделей, корзина, FAQ и мобильная навигация.

## Запуск

Требуется Node.js 20.9 или новее.

```powershell
cd D:\Files\Codex\Sites\Mangal
npm install
npm run dev
```

Открыть http://127.0.0.1:3000.

```powershell
npm run build
npm run start
```

## Шрифты

- Заголовки: **Alumni Sans, вес 900 (Black)**. Узкий тяжёлый рисунок, полноценная кириллица. Это самостоятельная бесплатная альтернатива, а не копия Druk. [Метаданные Google Fonts](https://github.com/google/fonts/blob/main/ofl/alumnisans/METADATA.pb).
- Интерфейс и основной текст: **Golos Text**, 400–600. [Метаданные Google Fonts](https://github.com/google/fonts/blob/main/ofl/golostext/METADATA.pb).
- Шрифты локальные, WOFF2, подключены через next/font/local; браузер не обращается к Google. Лицензии SIL OFL находятся в public/fonts.
- Если будет куплен **Druk Condensed Cyrillic**, можно подключить предоставленные лицензионные WOFF2-файлы вместо Alumni Sans в app/layout.js, затем проверить размеры и переносы в app/globals.css. [Официальная страница](https://type.today/en/druk_cond/xx-super).

## Данные и дальнейшее подключение

`data/products.js` — единый источник демонстрационных названий, цен, габаритов, толщины стали и комплектации. Все коммерческие данные и фотографии требуют замены перед запуском. Изображения являются сгенерированными визуализациями; промпты сохранены в public/images/README.md. Концепты находятся в concepts/.

`components/cart-provider.js` — управление корзиной и восстановление localStorage. Хранятся только идентификаторы моделей и количество. Суммы вычисляются из каталога. Неверные записи игнорируются; количество ограничено 1–99. Если браузер блокирует хранилище, корзина работает в памяти.

Оформление направлено через менеджера: кнопка в корзине ведёт к контактам в подвале. VK, Telegram и почта пока представлены неактивными кнопками; для активации заполнить href в store.contacts в data/products.js. Заказы не отправляются продавцу автоматически. Для подключения backend нужно реализовать серверный расчёт актуальных цен, наличия и доставки и API оформления заказа; текущие суммы в браузере нельзя использовать как доверенный расчёт. Подключение платежей должно опираться на реальные статусы платёжного сервиса.

Перед приёмом заказов добавить контакты и реквизиты в data/products.js и компоненты, подтвердить доставку, гарантию и возврат, заменить демонстрационный текст, добавить условия магазина. Затем обновить SEO-метаданные и robots в app/layout.js (сейчас индексирование демонстрации отключено).

## Проверки

```powershell
npx playwright install chromium
npm test
```

11 браузерных проверок: количество, суммы, удаление, сохранение после перезагрузки, пустая корзина, неверные сохранённые данные, страницы моделей, 404, FAQ, клавиатурное управление меню, reduced motion. Адаптивность проверяется на ширинах 320, 375, 390, 768, 1024, 1440 и 1920 px.

`node scripts/capture.mjs` при запущенном локальном сервере создаёт снимки главного экрана и каталога; для 390 и 1440 px — также полную страницу. Скриншоты находятся в screenshots/.

Пять WebP-изображений подготовлены встроенным image_gen. Исходные TTF сохранены рядом с WOFF2 для проверки кириллицы; для повторной подготовки `scripts/prepare-assets.py` нужны Pillow, fontTools и brotli, а также исходные изображения по записанным в скрипте локальным путям.
